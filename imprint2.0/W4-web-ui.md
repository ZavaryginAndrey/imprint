# W4 — Веб-UI

**Цель:** веб-клиент по [05-web-ux.md](05-web-ux.md) поверх tools сервера: мгновенный отклик,
правки видны в других вкладках без действий пользователя.

**Зависит от:** W3 · **Тег:** `web-w4`

**Статус (2026-09-30):** **W4 закрыт**; тег `web-w4` и выкладка на dev — после проверки владельцем.
Фаза шла двумя частями: **W4a** — рабочий десктопный клиент (закрыт, тег `web-w4a`) и **W4b** — полный UX
(реализован, `npm run check` и 50 сценариев e2e зелёные). Спек: [2026-09-30-w4-web-ui-design.md](../docs/superpowers/specs/2026-09-30-w4-web-ui-design.md);
планы: [W4a](../docs/superpowers/plans/2026-09-30-w4a-web-client.md), [W4b](../docs/superpowers/plans/2026-09-30-w4b-web-full-ux.md).
Решения по ходу: id новых строк выдаёт вызывающий и повтор узнаётся по занятому id (ADR 011); эпоха в
`GET /api/state` (риск W2 ниже закрыт); e2e входит подписанным тестовым cookie, без Google.
Решения плана W4b и хвосты — в конце файла; итог ревью P1 и грабли — в [HISTORY.md](../HISTORY.md).

## Архитектура

```
apps/web/src/
  app/          — точка входа, роутинг (адреса UX §2), store
  screens/      — Day (+ колонка Бэклога), Backlog (мобильный), History и Settings (заглушки)
  components/   — строка задачи, поле ввода, сайдбар, поповеры, плашки
  platform/     — api (tools, state), live (WebSocket), auth
  i18n/         — ru/en
```

- **Store:** последнее состояние с сервера + ожидающие вызовы. Действие = локальный `runTool` на
  `memoryContext` поверх состояния (оптимистично) → `POST /api/tools/:name` → замена серверным
  состоянием; отказ или сеть → откат + плашка «Не сохранилось · Повторить».
- **В `apps/web` нет правил домена (P1):** никаких расчётов дат, повторов, completion и размещения
  задач. Проверка — ревью + eslint-правило, запрещающее импорт date-библиотек в `screens/` и
  `components/`.
- React 19, dnd-kit (перетаскивание), Radix (поповеры, доступность), шрифты Playfair Display + Onest
  своим хостингом (UX §6).

## Грабли веба v1, которые не повторяем

- `tsc` без `noEmit` → дубли тестов (решено в W1).
- Токен OAuth в памяти → «переподключение» при каждой перезагрузке (теперь сессия-cookie).
- Данные с других устройств жили только в памяти → пустая страница до синхронизации (теперь
  состояние с сервера + кэш на чтение).
- `main.ts` на 500 строк → экраны и компоненты, лимит размера файла.

## Грабли лендинга, которые не повторяем

Найдены на живом лендинге ([landing/index.html](landing/index.html)) 2026-09-28; правила — в UX §3–§4.

- Окно, перерисованное по клику, отцепляет цель клика → корень экрана считает клик «вне строки»
  и сворачивает раскрытый ряд. Клики внутри окна (Radix Popover) не всплывают к строке.
- Эффекты наведения на мобильной раскладке в окне с мышью → раскрытая строка «прыгает». Наведение
  только в десктопной раскладке; раскрытая строка активна и на наведение не реагирует.
- Окно у точки клика выходит за край → мобильный: только лист снизу; десктоп: `collision`-обработка
  Radix (прижать и перевернуть), проверка в e2e у правого и нижнего края.
- Текст на кнопке переноса и «+ группа» раздувают ряд, иконки вылезают за строку → только иконки,
  ряд `nowrap`, проверка на 360 px.
- Своё окно с заготовками дат вместо календаря → нативный `input[type=date]`.

## Риски

- Оптимистичный показ расходится с сервером на границе суток → клиент считает `todayKey` той же
  функцией `time/` и теми же настройками; расхождение всё равно заменяется серверным ответом.
- Перетаскивание на мобильном конфликтует с прокруткой → на мобильном действия в ряду по тапу (UX §4).
- **Из W2:** после `DELETE /api/account` объект начинает с `rev 0`, а сессии других устройств
  остаются действительными (ADR 005) — их клиент по правилу «`rev` ≤ виденного игнорируется» будет
  молча показывать старое. До store W4: эпоха в `meta` (в `ToolCall`/`StateSnapshot`/push; смена
  эпохи сбрасывает `seenRev`) либо `rev`, монотонный через удаление. Меняет ожидания тестов W2
  `userStore`/`api` («rev 0 после удаления») — только с согласия пользователя.
- **Из W2:** сокет `/api/live` пропадает при деплое и выселении объекта → в store нужны переподключение
  и перечитывание `GET /api/state` при `onopen`.

## Решения плана W4b (приняты владельцем 2026-09-30)

1. **Контраст токенов:** `--amber-ink` для янтарного текста (светлая тема `#94560f`), светлый `--muted` → `#5c6380`,
   `--side-lab` → `#9098c0`, Meta `--danger` → `#f0a08c`; зачёркнутый `--done` меряется порогом 3:1 (`#767c89` / `#8e95bb`) —
   видимая смена бренда в светлой теме.
2. **Скриншот-тесты тем** (UX §8) — не в W4b; критерий остаётся хвостом; проверка локальная (`check` + `e2e`).
3. **Порядок групп на мобильном** — не в W4b (долгий тап занят правкой, перетаскивание спорит с прокруткой); порядок с десктопа виден.
4. **Выдвижной сайдбар** — только кнопкой ☰, без свайпа от края (конфликт с «Назад» в iOS).
5. **Окно «Шаги»:** шаги с кружками сверху, поля новых шагов ниже, «Подсказать шаги» дописывает поля, «Разбить»/Enter — `add_steps`; правки и удаления шагов нет.
6. **Название задачи и группы** сохраняются «по мере ввода» с паузой 300 мс; закрытие окна сохраняет сразу; пустое не отправляется.
7. **Пунктир при перетаскивании:** целевая колонка — янтарный пунктир, старая строка — пунктирная полупрозрачная, над курсором — поднятая копия.
8. **Клавиатура:** правка названия открывается и клавишей меню / Shift+F10 (событие `contextmenu`).

## Решения контролёра по ходу W4b (C1–C13)

Изменили текст плана; полный журнал — в `.superpowers/sdd/2026-09-30-w4b-web-full-ux/progress.md`.

- **C1:** оба `DndContext` получают скрытый контейнер для объявлений dnd-kit (иначе видимая `role="status"` ломает `getByRole("status")`).
- **C2:** e2e листа повтора идёт на `/g/all` с задачей Бэклога, а не на строке Дня с «пн» (иначе проходит только по понедельникам).
- **C3:** правый клик внутри окна (Popover, Dialog) не открывает «Название задачи».
- **C4:** e2e «перетаскивание не начинается с кружка» — настоящий drag от кружка, задача остаётся, затем клик отмечает.
- **C5:** убраны ставшие лишними импорты в `Sidebar.tsx` (`noUnusedLocals`).
- **C6:** скрытый заголовок окна — глобальный `visually-hidden`, не копия `.sr`.
- **C7:** удаление группы в редакторе сначала сбрасывает отложенное сохранение (`flush`); гонка с другой вкладкой принята.
- **C8:** `activeDays(task)` в `store/format.ts` — один владелец правила «остаточная маска разового не считается днями».
- **C9:** `MobileShell` переиспользует затемнение `Sheet.module.css`.
- **C10:** `:hover` иконок и меток — только в `@media (min-width: 1024px)`; метка группы в трее 44 px по высоте.
- **C11:** тест «иконка и цвет сохраняются» проверяет обе записи по порядку (в плане проверял слишком мало).
- **C12:** тесты `MobileRoot` и `PopoverAnchor` приведены к заголовкам (шаг «тап День → `/`»; якорь `vi.fn`).
- **C13:** мобильный откат при исчезнувшей группе — `replace` на `/g/all`, чтобы под любым экраном лежал День.

## Хвосты и вопросы владельцу

Вне W4b (по решениям плана):
- порядок групп на мобильном (решение 3); скриншот-тесты тем из UX §8 (решение 2);
- `dueKey` при смене часового пояса — W6 (Настройки, ADR 007).

Решения владельца (не сделано намеренно, нужно слово):
- **44 px:** правило выдержано для кружка, иконок трея и ☰. Содержимое листов (чипы повтора 32 px, × шага 28 px,
  иконки редактора группы 30 px, образцы цвета 24 px) и пункты выдвижного меню (~34 px) меньше.
- **Системная «Назад» на Android** при открытом меню или листе уходит по истории, а не закрывает окно.
- **Мобильный `remember()`** (`useRouteGuards`) затирает фильтр, с которым десктоп откроется в следующий раз — продуктовое решение.
- **Десктоп 1280 px:** строку под курсором можно схватить только за левые ~40–55 % — иконки наведения перекрывают конец по замыслу (UX §4).
- **Мобильная раскладка:** клавиша меню / Shift+F10 на кружке не открывает название (клавиатурное переименование ниже 1024 px).
- **Плашки** теперь над листами (z 50) и, пока видны, могут закрывать нижнюю часть листа.
- **Токены:** решение 1 плюс `--toast-act` (действие плашки) и счётчик выбранного пункта сайдбара — видимая смена бренда в светлой теме.
- **Проверить на устройствах** (в облаке недоступно): клавиатура iOS поверх нижних листов; клик на Android после отменённого долгого нажатия (`contextmenu`); системное меню iOS при долгом нажатии в сайдбаре.
- **`package-lock.json`** потерял ~20 записей `libc` (npm в облачном контейнере): перегенерировать своим npm при ближайшей установке.
