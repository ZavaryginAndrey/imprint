# Imprint 2.0 — веб-платформа

Imprint 2.0 — это **веб-платформа на сервере-хабе**: все действия продукта — tools одного реестра на
TypeScript, которые исполняются в Cloudflare Durable Object пользователя. Веб-UI, Claude (через MCP)
и позже Android ходят в один и тот же каталог. **Рабочее Android-приложение v1 остаётся отдельным
кодом** и подключается к платформе в фазе W7.

Дизайн-решение и его обоснование — в спеке
[2026-09-28-web-platform-roadmap-design.md](../docs/superpowers/specs/2026-09-28-web-platform-roadmap-design.md).
Прежний план (KMP-`core` для всех клиентов, Firestore, Ktor, HLC, переписанный Android) отменён;
его файлы удалены, история — в git.

## Замороженные документы

Не меняются; новые фазы опираются на них:

- [План tools](../docs/superpowers/plans/2026-09-28-web-tools.md) (фаза W0) и его
  [спек](../docs/superpowers/specs/2026-09-28-web-tools-design.md).
- [05-web-ux.md](05-web-ux.md) — UX и визуал веба, мокапы в [mockups/web/](mockups/web/).

Упоминания `core` в этих документах означают **`platform/packages/domain`**. Расхождения между ними
(удаление группы, цвет группы, перенос в День, подсказка шагов) закрываются новыми версиями tools в
W3b, а не правкой документов. Ссылки из `05-web-ux.md` на удалённый `05-web.md` ведут в историю git;
его содержание (роль веба, паритет, грабли веба v1) перенесено в [W4-web-ui.md](W4-web-ui.md).

## Почему переписываем

1. **Два «мозга».** Правила домена написаны на Kotlin и заново на TS, контракт данных
   синхронизируется вручную. Теперь правила одни — в `packages/domain`.
2. **Синхронизация выросла из бэкапа.** Полный снимок на Drive, ожидание 2–5 с. Теперь — сервер,
   оптимистичный UI и WebSocket.
3. **Нет границ слоёв.** `ChecklistRepository` на 762 строки, `main.ts` на 500. Теперь — tools по
   одному действию и тонкий UI.

## Как работать с фазой

Каждый файл фазы устроен одинаково: **цель → вход → задачи → результат → готово, когда → уроки →
риски → вне рамок**. Перед реализацией фаза получает свой план (`docs/superpowers/plans/`). Одно
изменение → тесты зелёные → сборка → проверка → отдельный коммит. Закрытая фаза получает тег
(`web-wN`) и запись в `HISTORY.md` с граблями.
