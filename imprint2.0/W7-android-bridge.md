# W7 — Мост Android и импорт v1

**Цель:** телефон (Android v1, свой код) и платформа видят одни данные; реальные данные v1 переезжают
на платформу без потерь истории.

**Зависит от:** W5, W6 · **Тег:** `web-w7`

## Первое решение фазы: механизм моста

Выбирается в начале фазы отдельным брейнштормом + ADR. Кандидаты:

| Вариант | Как | Плюсы | Минусы |
|---|---|---|---|
| Синхронизация строк | `SyncCoordinator` телефона вместо Drive шлёт серверу дельту строк и событий и забирает чужие (LWW по `updatedAt`, как `BackupMerge`) | Офлайн без оговорок; правила Android не дублируются на сервере | Второй канал рядом с tools |
| Вызовы tools | Каждое действие телефона — вызов tool; офлайн — очередь с доигрыванием | Один контракт буквально | Сервер должен принимать время и `dayKey` клиента; Android дублирует оптимистичный результат |

Требование к обоим: телефон обязан работать офлайн (плашка и будильники не ждут сеть), Room остаётся
локальной базой.

## Импортёр данных v1

Вход — файл экспорта v1 (`BackupData`, `version = 1`): `tasks`, `groups`, `events`, `settings`.
Правило v1: импорт — это merge, никогда не замена; битый файл не применяется частично. Повторный
импорт того же файла ничего не дублирует (merge по id).

| v1 | Платформа |
|---|---|
| `Task`, `Group`, `TaskEvent` | Те же строки (контракт общий), LWW по `updatedAt`; **`id` и `dayKey` событий сохраняются как есть** (DB-4) |
| `Group.color` (ARGB) | `colorKey` по таблице переноса из [05-web-ux.md §5](05-web-ux.md); `icon = tag` |
| `settings.resetHour/resetMinute` | `UserSettings` |
| `settings` дневных напоминаний, оверлея, темы | Не импортируются (настройки устройства) |
| `settings.evening*` | Игнорируются |

## Задачи

## Готово, когда

- [ ] Правка на телефоне видна в вебе и наоборот без ручного действия.
- [ ] Неделя без потерь данных; История в вебе совпадает с телефоном за тот же период.

## Уроки v1, применённые здесь

CRIT-1 (экспорт перед любым переносом), DB-4 (`dayKey` не пересчитывается), «импорт — merge, не замена».

## Риски

- Часы телефона в LWW → сравнить на реальных данных, при расхождениях — серверное время приёма.
- Drive-файлы v1 не удаляются — архив.

## Вне рамок

Переписывание Android. Android v1 меняется только в части транспорта синхронизации.
