# W6 — История, Настройки, экспорт

**Цель:** паритет веба с v1 по Истории, Настройкам и переносу данных файлом.

**Зависит от:** W4 · **Тег:** `web-w6`

## Вход

- [05-web-ux.md](05-web-ux.md) отложил детальный дизайн Истории и Настроек → **перед фазой —
  отдельный брейншторм** (черновик: [mockups/web/history-settings.html](mockups/web/history-settings.html)).
- `GroupBurndown`, `HistoryStats` v1 и их тесты.

## Задачи

- [ ] Брейншторм и дизайн Истории и Настроек (мир Meta, UX §6).
- [ ] Порт `HistoryStats`, `GroupBurndown` в `packages/domain/stats/`, тесты v1 как эталон.
- [ ] `GET /api/history?from&to` — события за период (глубже окна `GET /api/state`).
- [ ] История: счётчик, график 7/30, «По группам» (burndown). Без трендов «растёт/падает» (анти-фича).
- [ ] Настройки: `resetHour`, язык, тема браузера, аккаунт (выход, удаление), доступы агентов (W5).
- [ ] Экспорт и импорт файла в формате платформы; импорт — merge по id с LWW, битый файл не
      применяется частично.

## Результат

Веб умеет всё, что веб v1, и Историю телефона.

## Готово, когда

- [ ] История совпадает с v1 на общих фикстурах.
- [ ] Экспорт → импорт в чистый аккаунт даёт то же состояние; повторный импорт ничего не меняет.
