# W5 — MCP

**Цель:** Claude подключается к Imprint как коннектор и работает с задачами пользователя через тот же
реестр tools, что и веб-UI. Плюс выборка «впечатывания» без показа.

**Зависит от:** W3 · **Тег:** `web-w5`

## Вход

- `ALL_TOOLS` с zod-схемами и описаниями для агента (W0, W3).
- Вход через Google и объект пользователя (W2).

## Задачи

### A. MCP-сервер
- [ ] `McpAgent` в воркере (Streamable HTTP): каждый tool из `ALL_TOOLS` регистрируется один к
      одному (`name`, `description`, `input.shape`); вызов идёт в `UserStore` пользователя тем же
      путём, что `POST /api/tools/:name`.
- [ ] Результат tool возвращается как JSON без изменений (ошибки — данные, как в плане tools).
- [ ] Изменения от агента рассылаются по WebSocket — открытый веб видит их сразу.

### B. OAuth для MCP-клиентов
- [ ] OAuth-провайдер Cloudflare (OAuth 2.1, динамическая регистрация клиентов) поверх Google-входа из W2.
- [ ] Отзыв доступа агента из Настроек (в W6 — UI; здесь — эндпоинт).
- [ ] Подключение коннектором в Claude (dev и prod URL) проверено вручную.

### C. `get_imprint`
- [ ] Порт `ReminderContent.select` в `packages/domain/reminders/`: источник — только невыполненные
      задачи сегодняшнего Дня (решение №10), до 5 задач, гашение частотой (эпик 1), исключение
      облаков (эпик 2), резерв слота под отстающую группу (эпик 5). Одна функция отбора (P6).
- [ ] Tool `get_imprint` — только выборка, без записи `SHOWN` и без показа.
- [ ] Тесты v1 `ReminderContentTest` перенесены как эталон.

## Результат

«Добавь в Imprint…» в Claude пишет задачу, которую веб показывает сразу; `get_imprint` отдаёт тот
же набор, что показал бы телефон.

## Готово, когда

- [ ] MCP Inspector видит все tools со схемами; вызов каждого проходит на dev.
- [ ] Агент без токена или с токеном другого пользователя не видит чужих данных (тест).
- [ ] `get_imprint` совпадает с `ReminderContent.select` v1 на общих фикстурах.

## Риски

- Описания tools неудобны агенту → первая неделя использования — правка описаний, не схем.
- Агент делает много вызовов подряд → квота вызовов на пользователя в объекте.

## Вне рамок

Показ впечатывания на десктопе (W8, расширение Chrome), Android (W7).
