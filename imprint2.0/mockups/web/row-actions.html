Как это работает. Строка в покое чистая. На ховере справа: лейбл группы (главная маркировка; клик открывает выбор группы, у задачи без группы он пунктирный «+ группа»), дата, повтор (дни недели), шаги, удалить (со «Отменить»). Перенос между Днём и Бэклогом: перетащить строку, пунктир показывает место. Иконки ложатся поверх конца строки с мягким затуханием: текст не переносится и не прыгает при наведении. Клик по тексту: правка только названия, без чипов.
