Правило навигации. Верх сайдбара выбирает экран: День (две колонки), История, Настройки. Блок «Бэклог» выбирает фильтр правой колонки; клик по группе, пока открыта История или Настройки, возвращает к Дню с этим фильтром. Выбранный фильтр подсвечен текстом, выбранный экран полосой слева. Всё важное наверху: сайдбар не уходит за нижний край даже в невысоком окне.
