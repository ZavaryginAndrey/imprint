## 1. Базовое решение

**Фиксированный бренд «янтарь + navy», а НЕ Material You.** Динамический цвет системы отвергнут
сознательно: у продукта должен быть свой узнаваемый голос.

Три «визуальных мира», выбираются **по вкладке**:
- **Day** — светлый (единственная светлая поверхность)
- **Night / Evening** — глубокий navy (список «Вечер»)
- **Meta** — светлее navy панель (История, Настройки)

Плюс **опциональная** динамика по времени суток (только для «День» и «Бэклог»).

**Ключевая идея светлой темы:** *холодная земля, тёплые объекты.* Фон — прохладный slate
(родня navy-экранам), карточки задач — тёплый greige, никогда не чисто-белые (не бликует).


## 3. Динамическая тема (опция, выключена по умолчанию)

- **Окна по локальным часам:** `5–7 Dawn`, `8–16 Midday`, `17–20 Dusk`, иначе `Night`.
- **Midday = точные фиксированные токены LightDay**, **Night = точные DarkDay** — при включении
  тумблера днём/ночью визуального прыжка нет и лишних палитр не поддерживаем.
- Применяется **только к «День» и «Бэклог»**; Вечер/История/Настройки всегда navy.
- Каждый токен кроссфейдит `tween(700ms)`; окно пересчитывается раз в минуту; на первой композиции
  анимации нет (мгновенный вход на вкладку).

## 4. Типографика

**Playfair Display** (заголовки, голос бренда) + **Inter** (UI, тело, данные).

- Playfair — вариативный шрифт; вес **прибивается по оси `wght`** через `FontVariation.Settings`,
  иначе на малых кеглях рендерится слишком тонко. Взят тяжёлый конец: SemiBold…Black.
- Inter — Normal…ExtraBold; **италик синтезируется** (файла италика нет).

**Роли:**
```
display* / headline* / titleLarge   → Playfair (ExtraBold/Black)
titleMedium / titleSmall            → Inter SemiBold
body* / label*                      → Inter
```

**Именованные стили:**
```
ScreenTitle        Playfair Black 30/34, tracking -0.5   — «День», «Вечер», …
ScreenTitleAccent  Playfair Bold Italic 14/16, янтарь    — строка-подпись под заголовком
SectionLabel       Inter Bold 11, tracking +1.4, UPPER   — метки секций в meta-панелях
BigNumber          Inter ExtraBold 44, tracking -0.5, `tnum`  — крупные числа
```

⚠️ **Все цифры — табличные (`tnum`).** Serif-цифры «гуляли» по ширине; таймпикер пришлось
оборачивать в локальную тему с Inter.

**Подписи-акценты по вкладкам** (Playfair-italic янтарём под заголовком, перекличка с лендингом):
- День — «…что важно сегодня»
- Вечер — «…и перед сном»
- История — «…как идут дела»
- Настройки — «…под себя»

## 5. Компоненты и микро-паттерны (проверенные)

| Паттерн | Решение |
|---|---|
| Строка задачи | Карточка со скруглением, круглый чек-кружок слева |
| Отметка | **Только по галочке**, увеличенный хит-таргет; строка не кликабельна |
| Анимация отметки | `CircleCheck`: заливка/граница теплеют до `primary`, галочка проявляется, «pop» = сжатие 0.82 + пружина. Уважает системное «убрать анимации» (`ANIMATOR_DURATION_SCALE == 0`) |
| Перестановка списка | `Modifier.animateItem()` |
| Пустое состояние | Общий `EmptyState(icon, text)`: иконка 64dp α0.35 над тёплой фразой. День ☀ · Вечер 🌙 · История 📈 |
| Затухание краёв списка | `Modifier.fadingEdges(state)` — offscreen-слой + градиент `BlendMode.DstIn`, высота 28dp. Край гаснет только когда есть куда скроллить |
| Поле добавления | Одна «пилюля» `RoundedCornerShape(28dp)` в цвет `surface`, хайрлайн `outlineVariant`, при фокусе граница теплеет. «+» — `FilledIconButton` 36dp |
| Чипы дат | Над полем ввода: `Завтра · Выходные · +7 дней · 📅`. «Сегодня» **намеренно нет** |
| Удаление | Свайп (не кнопка-корзина) + Snackbar «Отменить» с полным переинсертом |
| Свайп Day-строки | **влево = удалить**, **вправо = в бэклог** |
| Вторичные действия | Долгий тап → одна поверхность (меню/диалог). У строки кончились дешёвые жесты — не плодить |
| График истории | Столбцы «выполнено за день», окно 7/30, подписи Пн–Вс, **сегодня — янтарём** |
| Рутина в списке | Только глиф ↻ (`Icons.Filled.Autorenew`, 16dp, primary) в конце строки. **Без** цвета/жирного/италика — было, убрали как шум |
| Ряды чипов/дней | `FlowRow`, никогда `Row + horizontalScroll` |

## 6. Тон копирайта (узко под СДВГ, решено v1.4.0)

Словарь: «роняешь задачи», «залипание», «облака вместо шагов», «подхвачу», «осядет в голове».
Никакого «стань продуктивнее», «достигай целей», «прокачай себя».

**Онбординг, экран 1 — эталон тона:**
> **Я подхвачу то, что ты роняешь**
> Это не тренажёр силы воли и не гонка за продуктивностью. Задачи, которые ты роняешь, приложение
> держит за тебя и время от времени показывает плашкой поверх экрана — не чтобы подгонять, а чтобы
> важное само осело в голове. Пустой список — и есть награда. Станет плашка не нужна — значит,
> сработало.

**Экран 2 (разрешения):**
> **Пара разрешений** · Чтобы напоминания доходили. Любое можно пропустить — что-то будет работать
> слабее, но приложение не сломается.

**Экран 3 (финал):**
> **Готово** · Добавь пару задач — и закрой приложение. Остальное оно возьмёт на себя.

**Пустые состояния:** «Добавьте задачи, которые нужно сделать сегодня» / «Добавьте вечерние дела:
почистить зубы, поставить будильник…» / «Задачи на потом. Добавьте дело — с датой или без.»

**Маркетинговая формула:** *единственное приложение, которое хочет, чтобы ты от него ушёл.*
