# Web Tools Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every important Imprint action in `web/` into a registry of zod-typed tools over a `ToolContext` port, so the new web UI and a future MCP server call the same code.

**Architecture:** `web/src/tools/` holds pure tool definitions (`{ name, description, input: z.object, run(ctx, input) }`) that read merged state and write rows/events to the web peer's draft only through `ToolContext`. A `memoryContext` backs tests (and later a Node MCP server); a `browserContext` backs the page. `main.ts` stops writing to the draft directly and calls `runTool`.

**Tech Stack:** TypeScript 5.6 (strict, `verbatimModuleSyntax`), Vite 6, Vitest 2, zod 3.25.

**Spec:** [docs/superpowers/specs/2026-09-28-web-tools-design.md](../specs/2026-09-28-web-tools-design.md)

## Global Constraints

- All paths below are relative to `web/` unless they start with `docs/`, `PLAN.md` or `app/`.
- Run commands from `web/`: tests `npx vitest run`, typecheck `npx tsc`, build `npm run build`.
- **Never modify or delete existing tests** (`src/*.test.ts`, 29 tests) — user policy. New test files only.
- `zod@^3.25` in `dependencies` — the first runtime dependency. Import as `import { z } from "zod"`.
- Tool names are `snake_case`; each has an agent-facing English `description` (≥ 20 chars).
- Tool results are JSON-serialisable: no classes, `Map`, `Set`, or `undefined` fields (use `null`).
- Errors are data: `{ ok:false, error }` with `error ∈ invalid_input | not_found | storage | unknown_tool`; rule refusals are `{ ok:true, changed:false, reason }` with `reason ∈ same_value | done_today | skipped_today | not_empty | empty_steps | already_in_day | already_in_backlog`.
- Every changed row gets `updatedAt = now`; every event gets a new `id`, `at = now`, `dayKey = ctx.todayKey()`, denormalised `title/groupId/isRepeating` from the task, `surface = null`, `deviceId = ctx.deviceId`. A tool reads `ctx.now()` **once** per run.
- Semantics mirror `app/src/main/java/com/imprint/app/data/ChecklistRepository.kt`; the web may only **append** events, never delete them.
- `PLAN.md`, `.claude/launch.json` and several `app/` files carry the user's uncommitted work — **never stage them**. Commit only the exact paths listed in each task.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Whitespace-only titles/names** (`"   "`) — must be rejected as `invalid_input`, never written as an empty task/group. Pinned in Task 4 (`add_task`) and Task 6 (`rename_group`).
2. **Acting on a peer's task** (a row that exists only in a phone snapshot, not in the draft) — the tool must write a same-id row with a newer `updatedAt` so the merged state (and the phone's LWW) shows the change. Pinned in Task 6 (`set_task_group` on a peer task).
3. **An old `localStorage` draft without a `groups` field** — must load as `groups: []`, not crash or drop tasks. Pinned in Task 1.
4. **Two actions in the same millisecond** (double-click done/undone) — the event order must follow the call order, not the random event id. Pinned in Task 2 (`monotonicClock`).
5. **Impossible or shifted dates** — `"2026-02-30"` must be `invalid_input`; a repeating definition with a past due date must **not** be promoted into the Day; the editor must show the task's local due date, not its UTC date (a UTC+2 midnight reads as the previous day). Pinned in Task 2 (`isoDate`), Task 5 (`set_due_date`), Task 10 (editor date formatting).

- [ ] **Step 2: Create `src/tools/result.ts`**

```ts
/**
 * Tool results are plain JSON (an MCP server returns them verbatim). Errors are data, not exceptions:
 * an agent must be able to read *why* an action did nothing.
 */

/** A rule refused the change, or there was nothing to change. */
export type Reason =
  | "same_value"
  | "done_today"
  | "skipped_today"
  | "not_empty"
  | "empty_steps"
  | "already_in_day"
  | "already_in_backlog";

export type ToolError = "invalid_input" | "not_found" | "storage" | "unknown_tool";

export type ToolOk = { ok: true; changed: boolean; reason?: Reason; [key: string]: unknown };
export type ToolFail = { ok: false; error: ToolError; message?: string; issues?: unknown };
export type ToolResult = ToolOk | ToolFail;

/** A write happened. */
export function changed(payload: Record<string, unknown> = {}): ToolOk {
  return { ...payload, ok: true, changed: true };
}

/** Nothing was written, for a stated reason. */
export function unchanged(reason: Reason, extra: Record<string, unknown> = {}): ToolOk {
  return { ...extra, ok: true, changed: false, reason };
}

/** A read-only answer (queries). */
export function found(payload: Record<string, unknown>): ToolOk {
  return { ...payload, ok: true, changed: false };
}

export function fail(error: ToolError, extra: { message?: string; issues?: unknown } = {}): ToolFail {
  return { ok: false, error, ...extra };
}
```

```ts
import type { Group, Task, TaskEvent } from "../types";

/**
 * The only thing a tool sees (web Tools spec). Reads are the merged state — peers + this peer's own
 * draft, LWW, tombstones kept — and they reflect this peer's writes at once. Writes go to the draft

  state(): MergedState;
  upsertTask(task: Task): void;
  upsertGroup(group: Group): void;
  appendEvent(event: TaskEvent): void;
  /** Epoch millis. A tool reads it once per run. */
  now(): number;
  /** Local calendar day, YYYY-MM-DD (as `todayDayKey`). */
  todayKey(): string;
  readonly deviceId: string;
}
```

```ts
import { z } from "zod";
import { doneTodayIds } from "../completion";
import { startOfDayMillis, uuid } from "../compose";
import { bit, isOn } from "../recurrence";
import type { EventType, Group, Task, TaskEvent } from "../types";
import type { ToolContext } from "./context";

// ---- zod atoms shared by tool inputs ----

export const id = z.string().min(1);

/** Trimmed, non-blank text — a whitespace-only title is invalid_input, never an empty row. */
export const text = z.string().trim().min(1);

/** A real local calendar date as YYYY-MM-DD ("2026-02-30" is rejected, not rolled over). */
export const isoDate = z
  .string()
  .regex(/^\d{4}-\d{2}-\d{2}$/, "expected YYYY-MM-DD")
  .refine((s) => {
    const [y, m, d] = s.split("-").map(Number);
    const dt = new Date(y, m - 1, d);
    return dt.getFullYear() === y && dt.getMonth() === m - 1 && dt.getDate() === d;
  }, "not a calendar date");

export const DAY_NAMES = ["mon", "tue", "wed", "thu", "fri", "sat", "sun"] as const;
export type DayName = (typeof DAY_NAMES)[number];
export const dayName = z.enum(DAY_NAMES);

/** Weekday names → the 7-bit RecurrenceMask (bit0 = Monday), as `recurrence.ts`. */
export function maskFromDays(days: readonly DayName[]): number {
  return days.reduce((mask, d) => mask | bit(DAY_NAMES.indexOf(d)), 0);
}

export function daysFromMask(mask: number): DayName[] {
  return DAY_NAMES.filter((_, i) => isOn(mask, i));
}

// ---- lookups over the merged state ----

/** Any row with this id, tombstones included. */
export function findTask(ctx: ToolContext, taskId: string): Task | null {
  return ctx.state().tasks.find((t) => t.id === taskId) ?? null;
}

export function liveTask(ctx: ToolContext, taskId: string): Task | null {
  const t = findTask(ctx, taskId);
  return t && t.deletedAt == null ? t : null;
}

export function liveGroup(ctx: ToolContext, groupId: string): Group | null {
  return ctx.state().groups.find((g) => g.id === groupId && g.deletedAt == null) ?? null;
}

/** Local midnight of today — the web's stand-in for the phone's logical-day start (decision №25). */
export function todayStart(ctx: ToolContext): number {
  return startOfDayMillis(ctx.todayKey());
}

export function isDoneToday(ctx: ToolContext, taskId: string): boolean {
  return doneTodayIds(ctx.state().events, ctx.todayKey()).has(taskId);
}

export function hasEventToday(ctx: ToolContext, taskId: string, type: EventType): boolean {
  const key = ctx.todayKey();
  return ctx.state().events.some((e) => e.taskId === taskId && e.dayKey === key && e.type === type);
}

/** A journal event for [task], denormalised like `ChecklistRepository.logEvent`. */
export function taskEvent(ctx: ToolContext, type: EventType, task: Task, at: number): TaskEvent {
  return {
    id: uuid(),
    taskId: task.id,
    type,
    at,
    dayKey: ctx.todayKey(),
    title: task.title,
    groupId: task.groupId,
    isRepeating: task.isRepeating,
    surface: null,
    deviceId: ctx.deviceId,
  };
}

/**
 * A clock that never repeats a millisecond. Completion orders events by `(at, deviceId, id)`; two
 * clicks in one millisecond would otherwise be ordered by a random event id.
 */
export function monotonicClock(read: () => number = Date.now): () => number {
  let last = -Infinity;
  return () => {
    const t = Math.max(read(), last + 1);
    last = t;
    return t;
  };
}
```

```ts
import { draftToSnapshot, type Draft } from "../draft";
import { mergeSnapshots } from "../merge";
import type { BackupData } from "../types";
import type { ToolContext } from "./context";

export interface MemoryContext extends ToolContext {
  /** What this peer wrote — inspect it in tests; a Node MCP server would persist it. */
  readonly draft: Draft;
}

export interface MemoryOptions {
  peers?: BackupData[];
  /** First `now()`; each later call returns +1ms. Default 2026-09-28 12:00 local. */
  start?: number;
  todayKey?: string;
  deviceId?: string;
}

/** An in-memory ToolContext: fixed peers, a private draft, a deterministic clock. */
export function memoryContext(opts: MemoryOptions = {}): MemoryContext {
  const peers = opts.peers ?? [];
  const draft: Draft = { tasks: [], groups: [], events: [] };
  let clock = opts.start ?? new Date(2026, 8, 28, 12, 0, 0).getTime();
  const todayKey = opts.todayKey ?? "2026-09-28";

  function upsert<T extends { id: string }>(list: T[], row: T): void {
    const i = list.findIndex((r) => r.id === row.id);
    if (i >= 0) list[i] = row;
    else list.push(row);
  }

  return {
    draft,
    deviceId: opts.deviceId ?? "web-test",
    state: () => mergeSnapshots([...peers, draftToSnapshot(draft)]),
    upsertTask: (t) => upsert(draft.tasks, t),
    upsertGroup: (g) => upsert(draft.groups, g),
    appendEvent: (e) => void draft.events.push(e),
    now: () => clock++,
    todayKey: () => todayKey,
  };
}
```

```ts
export const ALL_TOOLS: ToolDef[] = [];

export function runTool(

  rawInput: unknown,
  tools: readonly ToolDef[] = ALL_TOOLS,
): ToolResult {
  const tool = tools.find((t) => t.name === name);

  try {
    return tool.run(ctx, parsed.data);
  } catch (e) {
    return fail("storage", { message: e instanceof Error ? e.message : String(e) });
  }
}
```

```ts
/** JVM `String.hashCode()`: int32, `h = 31*h + utf16unit`. */
export function javaStringHashCode(s: string): number {
  let h = 0;
  for (let i = 0; i < s.length; i++) h = (Math.imul(31, h) + s.charCodeAt(i)) | 0;
  return h;
}

  const n = GROUP_PALETTE.length;
  return GROUP_PALETTE[((javaStringHashCode(id) % n) + n) % n];
```

```ts
import { z } from "zod";
import { buildContribution, startOfDayMillis } from "../compose";
import { doneEvent, tombstone } from "../edit";
import { LOCATION_BACKLOG, LOCATION_DAY, type Task } from "../types";
import type { ToolContext } from "./context";
import { defineTool, type ToolDef } from "./define";
import { changed, fail, unchanged } from "./result";
import { dayName, findTask, id, isDoneToday, isoDate, liveGroup, liveTask, maskFromDays, taskEvent, text } from "./support";

/**
 * Task tools. Each mirrors a `ChecklistRepository` mutation so the phone folds the web's rows in with
 * `BackupMerge` exactly as if it had written them itself (web Tools spec).
 */

export const addTask = defineTool({
  name: "add_task",
  description:
    'Add a task. where="day" puts it on today\'s list; where="backlog" parks it, optionally with a due date (YYYY-MM-DD). ' +
    "repeatDays (mon..sun) makes it a repeating backlog definition that appears on those weekdays. groupId must be an existing group.",
  input: z.object({
    title: text,
    where: z.enum(["day", "backlog"]),
    groupId: id.nullish(),
    dueDate: isoDate.nullish(),
    repeatDays: z.array(dayName).nullish(),
  }),
  run(ctx, i) {
    const groupId = i.groupId ?? null;
    if (groupId != null && !liveGroup(ctx, groupId)) return fail("not_found", { message: `group ${groupId}` });
    const toDay = i.where === "day";
    const { task, event } = buildContribution(
      {
        title: i.title,
        toDay,
        groupId,
        dueDate: !toDay && i.dueDate ? startOfDayMillis(i.dueDate) : null,
        recurrenceMask: maskFromDays(i.repeatDays ?? []),
      },
      ctx.deviceId,
      ctx.now(),
      ctx.todayKey(),
    );
    ctx.upsertTask(task);
    ctx.appendEvent(event);
    return changed({ task });
  },
});

export const renameTask = defineTool({
  name: "rename_task",
  description: "Rename a task. For a repeating task this renames its definition, so every future appearance.",
  input: z.object({ taskId: id, title: text }),
  run(ctx, i) {
    const task = liveTask(ctx, i.taskId);
    if (!task) return fail("not_found");
    if (task.title === i.title) return unchanged("same_value");
    const next: Task = { ...task, title: i.title, updatedAt: ctx.now() };
    ctx.upsertTask(next);
    return changed({ task: next });
  },
});

export const deleteTask = defineTool({
  name: "delete_task",
  description: "Delete a task (a tombstone; its history stays in the journal and restore_task brings it back).",
  input: z.object({ taskId: id }),
  run(ctx, i) {
    const task = liveTask(ctx, i.taskId);
    if (!task) return fail("not_found");
    const now = ctx.now();
    const gone = tombstone(task, now);
    ctx.upsertTask(gone);
    ctx.appendEvent(taskEvent(ctx, "DELETED", task, now));
    return changed({ task: gone });
  },
});

export const restoreTask = defineTool({
  name: "restore_task",
  description: "Undo delete_task: bring a deleted task back where it was.",
  input: z.object({ taskId: id }),
  run(ctx, i) {
    const task = findTask(ctx, i.taskId);
    if (!task) return fail("not_found");
    if (task.deletedAt == null) return unchanged("same_value");
    const back: Task = { ...task, deletedAt: null, updatedAt: ctx.now() };
    ctx.upsertTask(back);
    return changed({ task: back });
  },
});

export const setDone = defineTool({
  name: "set_done",
  description:
    "Mark a task done (done=true) or not done (done=false) for today. Completing a step of a split task " +
    "moves the next step of that chain from the backlog into today (returned as promoted).",
  input: z.object({ taskId: id, done: z.boolean() }),
  run(ctx, i) {
    const task = liveTask(ctx, i.taskId);
    if (!task) return fail("not_found");
    if (isDoneToday(ctx, task.id) === i.done) return unchanged("same_value");
    const now = ctx.now();
    ctx.appendEvent(doneEvent(task, i.done, ctx.deviceId, now, ctx.todayKey()));
    const promoted = i.done ? promoteNextStep(ctx, task, now) : null;
    return changed({ task, promoted });
  },
});

/** The auto-conveyor (`promoteNextChainStep`): next live backlog step of the same `parentId`, lowest `position`. */
function promoteNextStep(ctx: ToolContext, task: Task, now: number): Task | null {
  if (task.parentId == null) return null;
  const next = ctx
    .state()
    .tasks.filter(
      (t) => t.deletedAt == null && t.parentId === task.parentId && t.id !== task.id && t.location === LOCATION_BACKLOG,
    )
    .sort((a, b) => a.position - b.position)[0];
  if (!next) return null;
  const moved: Task = { ...next, location: LOCATION_DAY, enteredDayAt: now, updatedAt: now };
  ctx.upsertTask(moved);
  ctx.appendEvent(taskEvent(ctx, "MOVED_TO_DAY", moved, now));
  return moved;
}

export const TASK_TOOLS: ToolDef[] = [addTask, renameTask, setDone, deleteTask, restoreTask];
```

```ts
import { uuid } from "../compose";

/** Group tools — mirror the group mutations of `ChecklistRepository` (SPEC §8.1). */

/** A fresh group row after the last live one; colour defaults to the palette pick for its id. */
export function newGroup(ctx: ToolContext, name: string, color: number | null, now: number): Group {
  const positions = liveGroups(ctx.state()).map((g) => g.position);
  const groupId = uuid();
  return {
    id: groupId,
    name,
    position: positions.length > 0 ? Math.max(...positions) + 1 : 0,
    isCollapsed: false,
    color: color ?? colorForId(groupId),
    createdAt: now,
    updatedAt: now,
    deletedAt: null,
  };
}

function liveTaskCount(ctx: ToolContext, groupId: string): number {
  return ctx.state().tasks.filter((t) => t.deletedAt == null && t.groupId === groupId).length;
}

  run(ctx, i) {
    const group = newGroup(ctx, i.name, i.color ?? null, ctx.now());
    ctx.upsertGroup(group);
    return changed({ group });
  },
});

  description: "Rename a group.",

    if (!group) return fail("not_found");
    if (group.name === i.name) return unchanged("same_value");

    return changed({ group: next });

  },

export const deleteGroup = defineTool({
  name: "delete_group",
  description:
    "Delete a group. Only an empty group can be deleted; otherwise nothing changes (reason not_empty, with taskCount) — move or delete its tasks first.",
  input: z.object({ groupId: id }),
  run(ctx, i) {
    const group = liveGroup(ctx, i.groupId);
```

```ts
import { z } from "zod";
import { doneTodayIds } from "../completion";
import { liveGroups, liveTasks } from "../merge";
import { LOCATION_BACKLOG, LOCATION_DAY, type Group, type Task } from "../types";
import { defineTool, type ToolDef } from "./define";
import { found } from "./result";

/**
 * Flat reads over the merged state. **Not** the phone's computed Day: no repeating appearances, no
 * rollover, no clouds (decision №30) — that projection arrives with get_imprint (step 2).
 */

const byPosition = (a: Group, b: Group) => a.position - b.position || a.name.localeCompare(b.name);
const byTaskPosition = (a: Task, b: Task) => a.position - b.position || a.createdAt - b.createdAt;

export const listDay = defineTool({
  name: "list_day",
  description:
    "List today's one-shot tasks (in arrival order) with doneToday. Repeating tasks' appearances are not included — the phone computes those.",
  input: z.object({}),
  run(ctx) {
    const state = ctx.state();
    const done = doneTodayIds(state.events, ctx.todayKey());
    const tasks = liveTasks(state)
      .filter((t) => t.location === LOCATION_DAY && !t.isRepeating)
      .sort((a, b) => (a.enteredDayAt ?? a.createdAt) - (b.enteredDayAt ?? b.createdAt))
      .map((t) => ({ ...t, doneToday: done.has(t.id) }));
    return found({ tasks });
  },
});

export const listBacklog = defineTool({
  name: "list_backlog",
  description: "List the backlog (including repeating definitions) by group, plus tasks in no group.",
  input: z.object({}),
  run(ctx) {
    const state = ctx.state();
    const groups = liveGroups(state).sort(byPosition);
    const groupIds = new Set(groups.map((g) => g.id));
    const backlog = liveTasks(state).filter((t) => t.location === LOCATION_BACKLOG).sort(byTaskPosition);
    return found({
      groups: groups.map((group) => ({ group, tasks: backlog.filter((t) => t.groupId === group.id) })),
      ungrouped: backlog.filter((t) => t.groupId == null || !groupIds.has(t.groupId)),
    });
  },
});

export const listGroups = defineTool({
  name: "list_groups",
  description: "List groups in order, each with the number of live tasks in it (Day and backlog).",
  input: z.object({}),
  run(ctx) {
    const state = ctx.state();
    const tasks = liveTasks(state);
    const groups = liveGroups(state)
      .sort(byPosition)
      .map((g) => ({ ...g, taskCount: tasks.filter((t) => t.groupId === g.id).length }));
    return found({ groups });
  },
});

export const QUERY_TOOLS: ToolDef[] = [listDay, listBacklog, listGroups];
```

```ts
 * writes through `draft.ts` (localStorage) and hands the new draft back via `onWrite`.

export function browserContext(opts: {
```
